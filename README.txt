WEBMAKER PRO
=============
Nieuwe versie met:
- Meerdere pagina's toevoegen, hernoemen en verwijderen.
- Per pagina eigen onderdelen.
- Primaire kleur, accentkleur, achtergrondkleur en tekstkleur.
- Kleuren van losse blokken aanpassen.
- Pagina's en project worden automatisch in localStorage opgeslagen.
- Download een pagina als losse HTML-website.
- Volledig HTML/CSS/JavaScript, dus geen Java-installatie nodig.

Gebruik:
1. Pak de ZIP uit.
2. Open index.html.
3. Maak pagina's met '+ Pagina'.
4. Pas kleuren links aan.
5. Klik een blok aan om het rechts te bewerken.
6. Klik 'Website downloaden' om de huidige pagina als HTML te exporteren.
